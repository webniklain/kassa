# Касса — структура данных

## Общий принцип

В первой версии приложение хранит только те данные, которые нужны для:

- расчёта остатка;
- учёта расходов и приходов;
- группировки расходов по категориям;
- совместной работы Андрея и Наташи в будущем.

Структура должна оставаться простой и понятной.
